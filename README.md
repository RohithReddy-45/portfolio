# Rohith Reddy - Portfolio

This is my personal portfolio website built with Astro, React, and Tailwind CSS to showcase my projects and skills.

**Live URL:** [https://rohith-reddy.vercel.app](https://rohith-reddy.vercel.app)

## 🛠️ Tools and Technologies Used

- **Framework:** [Astro](https://astro.build/)
- **UI Library:** [React](https://react.dev/) with [TypeScript](https://www.typescriptlang.org/)
- **Styling:** [Tailwind CSS](https://tailwindcss.com/)
- **Animations:** [Rombo](https://rombo.co/) and [Framer Motion](https://motion.dev/)
- **pqoqubbw/icons:** [https://icons.pqoqubbw.dev/](https://icons.pqoqubbw.dev/)
- **Deployment:** [Vercel](https://vercel.com/)

## 🚀 How to Run Locally

1.  **Clone the repository:**
    ```bash
    git clone https://github.com/RohithReddy-45/portfolio.git
    ```
2.  **Navigate to the project directory:**
    ```bash
    cd portfolio
    ```
3.  **Install dependencies:**
    ```bash
    pnpm install
    ```
4.  **Start the development server:**
    ```bash
    pnpm dev
    ```
    The application will be available at `http://localhost:3000`.
